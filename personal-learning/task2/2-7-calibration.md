# 2.7 校准记录

学习者在聊天中给出的目标风格是“克制、简洁、优美、有深意，有些地方会有趣”，并明确同意用生成的三到五篇文章代替本人原创范文来做这次练习。因此我生成了[四篇范文](2-7-generated-samples.md)，再据此更新[写作 Skill](personal-cn-writing/SKILL.md)。这些样本只是目标风格的演示，不是学习者的文章；本次是**按描述做风格设计**，不是个人文风复现测试。

## 从范文提炼出的规则

| 目标 | 样本中的处理 | 写入 Skill 的规则 |
| --- | --- | --- |
| 克制 | 把“十二格都是零”与不能推广的边界放在一起 | 先观察，再下结论 |
| 简洁 | 每段只推进一个判断，不堆同义形容词 | 短句保留自然节奏 |
| 优美、有深意 | 用“工具带回了什么，模型拿走了什么”连接过程与判断 | 一处贴合事实的意象即可 |
| 偶尔有趣 | “摘要没有瘦身，倒像添了附录” | 笑点从结果中长出，可以不用 |

## 新题目试写：状态栏对照

**改写前，泛化稿**：通过对状态栏功能的全面实验，我深刻认识到了它的重要性，并显著提升了对 Agent 工作机制的理解。实验结果充分说明，状态栏可以有效改善任务表现。

**按 Skill 改写后**：我让同一个读文件任务分别带上、关掉状态栏。两次都只调用了一次工具，也都答对了。状态栏像贴在桌角的一张便签；这回任务太简单，我还看不出它帮了多少忙。

**对照**：删去无法由实验支持的“全面”“显著提升”“有效改善”；改用两条可核查的结果；只留一处轻巧意象；结尾限定为这次简单任务。改写由助手完成，**没有经过学习者逐句修改或验收**。后续若有真实作品或反馈，再用它们替换生成样本进行校准。

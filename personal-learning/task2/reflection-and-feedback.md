# Task 2｜学习心得

本机那个 0.6B 模型跑起来很快，也真的会调用工具。我原本以为接下来只要检查工具有没有返回就行，结果它先选错天气工具，后来又把天气的观测时间当成当前时间。字段提示得更明确后，它连 UTC 偏移的正负号还是写反了。小模型的这些错误挺具体，比一句“效果一般”更能让我记住问题出在哪里。

这一章还有几次结果跟名称对不上。滑动窗口的缓存占比很高，题却没做完；六种压缩策略跑完，保存的文本都比原文长；提示注入的十二组条件全是零，连没有防御的基线也是零。我现在看到“缓存”“压缩”“防御”这些词，会先去翻对应的结果，不急着替它们解释成功。

写作 Skill 那部分，我按自己给出的几个风格词做了练习。四篇样文都是生成的，并不是我以前写过的东西。这次练习能帮我看哪些句子读着别扭，但还谈不上复现个人文风。

# Task 1 学习心得与课程反馈

## 学习心得

学习第 1 章后，我对 Agent 的认识从“模型会调用工具”变成了“模型在每一轮依据它真正看见的内容作决定”。离线轨迹让我看清了思考、行动和观察如何接续：第一次搜索没有覆盖完整问题，才会有第二次搜索。

实际做上下文对照时，我看到两个模式都得出了 4000，但过程差别很大。完整模式只调用一次计算器；移除工具结果后，模型反复尝试计算器和代码工具，最后自己算出答案。这让我意识到，只看最终数字会错过关键问题：工具执行成功并不意味着模型收到了结果，更不意味着答案得到了工具结果的支持。

我接下来希望养成查看执行轨迹的习惯，分别记录模型看到了什么、工具做了什么，以及最终结论依据什么。对于更复杂的任务，我也会避免用一次运行就断定某种设计一定更好。

## 一句话课程反馈

通过第 1 章的轨迹和对照实验，我更直观地理解了上下文如何影响 Agent 的行动，也学会了同时检查结果与过程。

# Task 1｜学习心得

第 1 章里最折腾我的，其实是 1-3。密钥、地域、请求格式挨个查过，程序终于给出“吉隆坡和新加坡约 315.29 公里”时，我没有马上把这句复制进结论，而是先打开结果文件，确认里面真有完成的搜索和 Python 调用。折腾过一次之后，我对“已搜索、已计算”这种表述反而没那么容易信了。

前面的计算器对照也有类似的意思。两组都答出 4000，但完整上下文只叫了一次工具，隐藏工具返回的那组绕了六次。我如果只交一张最终答案的截图，这个差别就没了。后来补做几种上下文模式，“无历史”一直重复调用，“无先前推理”却很快答对。结果没有按我想象的方向排队。

1-4 的海报让我有点意外。原需求明明指定了文案，改写提示词时却把文字排除掉了。这样看图之前，问题其实已经出现了。以后再做类似的工作流，我想先盯住需求在每一步有没有被带下去；图片好不好看，可以稍后再谈。

这些实验有本机运行，也有离线示例和仓库里留下的记录。我在笔记里尽量写清是哪一种，免得回头看时连自己做过什么都记混了。

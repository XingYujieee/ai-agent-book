# Task 1｜学习心得

第 1 章里，我最先记住的是那条离线搜索轨迹：第一次搜完，信息还不够，模型又搜了一次。Agent 在我眼里不再只是“问一句、答一句”。不过那份搜索结果是预设的，不能拿它证明真的联网了。这两个事实得一起记。

1-1 的计算器对照给我的提醒更直接。两组最后都答了 4000，一组只调用一次工具，另一组看不到工具返回，兜了好几圈。只看答案，我会以为它们做得一样。后来补做的几组里，删掉历史会让模型反复调用；删掉先前推理，在这个简单题上倒没有坏事。我现在不敢预先替实验写结论了。

做首都距离题时，我经历过一阵 API 排障。等它终于跑通，我先去结果文件找真正完成的搜索和代码调用，再看“吉隆坡—新加坡约 315.29 公里”这句结论。那时我才觉得数字有了来处。

1-4 的海报更像一次小小的反例：原要求有指定文案，改写后的提示词却把文字排除了。图片是否好看先放一边，用户要的东西已经在中途丢了。以后遇到多步骤工作流，我会先对照原需求，看每一步有没有把它带到下一步。

这四项里，有我本机的对照，也有离线演示和复用的历史记录。我会继续把它们分开写，免得一句“做完了”盖住过程的差别。

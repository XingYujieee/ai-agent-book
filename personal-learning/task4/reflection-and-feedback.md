# Task 4 学习心得

这一章让我重新看待“给 Agent 更多工具”这件事。工具多，选择也多；如果每个工具的说明都挤在眼前，模型还没开始做事，就先背了一本目录。离线对照里，主动发现确实省下了许多上下文。可作者的真实模型两组都做完了三题，我不能把“更省”顺手写成“更准”。

感知工具的演示很朴素：先找相关行，再读原文件。我喜欢这种节奏。看见一点线索，再决定要不要看得更深。多模态样例则提醒我，材料一旦被转成文字，图上的数字可能就留在了原地；答案不是没有，只是提取过程把它落下了。

执行工具给我的印象不是写入成功，而是它拒绝了两件事：一段写坏的代码，和一个越过工作区的路径。拒绝得明白，后面的人才知道怎样修。协作工具也一样，超时就是超时；迟到的批准不能替已经结束的请求改口。

我现在会在每次工具调用前多问一句：这一步究竟要观察、改变，还是等待别人？边界清楚了，Agent 才不容易把能力误当成许可。

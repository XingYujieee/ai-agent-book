# Task 4｜学习心得

4-1 的离线演示里，126 个工具全部塞进上下文，用了 93,040 token；按需找工具只用了 7,796。这个差距挺醒目。我去看作者用真实模型跑的记录，两组又都做对了三题，所以这里能说的只是工具目录变轻了，不能顺手说模型变聪明了。

4-2 我只跑了本地离线流程：先 grep，再读文件，最后查本地知识库。这个顺序很合我的习惯，知道要找哪几行，再决定要不要读完整份材料。4-3 那张柱状图里，Q4 的 180M 一眼能看见，抽成 PDF 文字后却找不到。看似是同一份材料，交给模型的内容已经不同了。

我还试了 4-4 的文件写入：正常的 Python 文件写进去了，语法错的和越界路径都被拒绝。4-5 则碰上 Windows 等待管道的问题，改完后相关测试才通过。相比“工具能做多少事”，我这次更在意它什么时候停下来、怎样告诉我没做成。

私有日历、邮件和通知渠道的正式门禁还缺授权。我把这几项留在进度表里，没有拿离线结果替它们打勾。

# Task 4｜学习心得

第 4 章我先从工具数量入手。离线对照里，把 126 个工具说明一次放进去，用了 93,040 token；按需发现用了 7,796。省下来的空间很直观。但作者的真实模型两组都做对了三题，所以我只把它记作“更省”，不写成“更准”。

感知工具这次做得很简单：先找相关行，再读文件。这样的顺序我用得上。多模态样例里，柱状图写着 Q4 是 180M，PDF 抽出的文字却没有那个数。原来信息可以就在眼前，只是在转换格式时掉了队。

执行工具让我印象深的反而是两次拒绝：坏掉的 Python 代码没写进去，工作区外的路径也没写进去。协作工具的超时测试则让我看到，迟来的回复不能替已经结束的请求作决定。这些边界，比“工具能做多少事”更值得我先弄清楚。

我把本机离线结果和作者留下的正式记录分开了。私有日历、邮件和通知渠道还缺授权；没有跑到的地方，我就先留白。

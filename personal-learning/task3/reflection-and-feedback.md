# Task 3｜学习心得

做第 3 章时，我最有印象的是那个关于两辆车的例子。第一次检索只找到一段线索，接着按车型再搜，才把另一段接上。看结果的时候会觉得“多搜一次就好了”，但离线演示里的下一问本来就是写好的；真让模型自己决定，未必每次都能问到点上。

BM25 的结果也很直白。关键词写得准，它几乎立刻找到；换成同义说法，就找不到了。我以前会把这叫作“记忆不好”，现在更愿意先看它用什么方式找。没被检索出来，和根本没存进去，是两回事。

脱敏那组更难选。规则保留了较多原文，却漏了敏感信息；混合方法在十二条合成日志里没有残留泄漏，也删掉了一些有用的内容。我还没有一个一劳永逸的答案，只知道以后保存和调用记忆时，得把来源、时间和原文线索留住。

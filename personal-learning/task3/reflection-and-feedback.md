# Task 3 学习心得

学这一章时，我开始意识到，记忆的难处不只是“存下来”。它还要在合适的时候回来，而且回来的是那条仍然有效、有出处的事实。把一段对话压成卡片，省了空间；压掉时间和语境，也可能省掉答案。

本机跑 BM25，我看到精确词几乎一找就中，同义词却像站在门外，没有被认出来。后来读稠密检索、融合与重排，我不再期待某一个算法解决所有问题。工具各有眼睛，也各有盲点。

两辆车的记忆案例让我印象很深。一次检索只带回一半线索，接着按车型追问，才把两段会话接起来。多搜索确实能补全证据；只是离线演示里的下一问事先写好了。我得记住，演示了路径，不等于模型自己走对了路。

日志脱敏的结果也很实在：规则保留了更多可读信息，却漏掉敏感值；混合方法在十二条合成日志里堵住了泄漏，也删掉了一些有用内容。安全和可用性在这里没有握手言和，只能继续量。

这一章给我留下一个朴素的检查习惯：先问事实从哪里来，再问它为什么被找出来，最后问答案有没有真正用对。记忆不是一只越装越满的箱子；它更像一张不断修改的地图。地图可以简洁，路不能画错。

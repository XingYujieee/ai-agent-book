## 运行过程中修过的问题

- 视频剪辑在 Windows 找不到默认字体，增加本机字体路径并按 ffmpeg 过滤器规则转义，重新跑过剪辑测试和冒烟流程。
- 异步取消测试用了 POSIX 进程探测，Windows 路径改为核对已等待结束的子进程返回码；取消、进度冻结和恢复仍保留检查。
- OpenVLA 预检遇到无效目录时没有返回结构化失败，扩展对 OS 路径错误的处理后复测通过。
- 安全门禁在 Windows 没认出双重 URL 解码后的 POSIX 绝对路径，补上跨平台路径识别；候选测试里的反斜杠字面量也修正了。
- 一批封存材料被 Git 的 Windows 换行转换影响。只在“与原始 Git 文件的差别完全是 CRLF→LF”时恢复原字节，恢复清单单独保存，未改任何预期哈希。
- 语音 SFT 脚本在导入时就要求完整训练栈，导致只检查标签和 collator 也失败。将训练专用依赖放到实际训练入口后，四项辅助函数测试通过；这没有产生新的语音模型权重。

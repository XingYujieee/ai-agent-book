# Task 0 学习心得：从“会用 AI”到理解 Agent 如何工作

读完《深入理解 AI Agent》的引言，我对 Agent 有了一个更清晰的起点：**Agent = LLM + 上下文 + 工具**。以前使用 AI 时，我更多关注它给出的答案；现在我开始留意，它在做决定时看到了哪些信息，又能通过哪些工具采取行动。

这三个部分中，“上下文”最值得我继续思考。同一个模型，如果缺少任务背景，或者没有看到关键的工具结果，就可能做出不同的判断。这让我意识到，设计 Agent 不只是写好一句提示词，还要安排好信息如何进入系统、何时更新，以及模型怎样利用这些信息完成任务。

引言也改变了我对“做出一个 Agent”的理解。让程序跑通只是第一步；如果希望它完成较长、较复杂的任务，还需要检查结果、发现错误，并根据实际反馈改进。接下来学习各章时，我想带着三个问题阅读和实践：**Agent 此刻知道什么？它能做什么？我怎样判断它做对了？**

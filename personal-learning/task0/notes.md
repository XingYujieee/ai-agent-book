# Task 0｜引言笔记

引言先给了一个很方便记的式子：`Agent = LLM + 上下文 + 工具`。我把它当成读后面章节时的一张简图。模型负责判断下一步；上下文包括任务、对话、规则和刚拿到的工具结果；工具负责向外查信息或者做事。

这个式子也提醒我，不能只盯着模型。如果一次回答出了问题，要回头看它当时能读到哪些信息。比如工具已经算出结果，但返回值没有进入下一轮上下文，模型仍可能继续猜。反过来，给它很多工具，也不保证它会选对。

后面读案例时，我准备顺着一条轨迹看：用户要什么，模型看到了什么，它实际调用了什么，最后的回答怎么接上这些结果。光记住“Agent 能用工具”，对我来说还是太宽泛了。

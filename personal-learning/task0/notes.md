# Task 0 学习笔记：引言

## 一、核心公式

**Agent = LLM + 上下文 + 工具**

| 组成 | 作用 | 可以追问的问题 |
| --- | --- | --- |
| LLM | 理解任务、思考并作出决策 | 下一步应该做什么？ |
| 上下文 | 提供当前可用的信息 | Agent 此刻知道什么？ |
| 工具 | 获取信息或执行操作 | Agent 能对外做什么？ |

一个直观的比喻是：LLM 是大脑，上下文是眼睛，工具是手脚。上下文不只包含外部信息，也包含对话历史和工具说明。

## 二、本书要解决的问题

本书关注的是：**如何依据可解释、可验证、可复用的原则设计 Agent**。学习目标不只是让演示程序运行，还要理解架构选择、能力边界和工程取舍。

- **真实反馈**能暴露 Agent 在长任务和复杂场景中的问题。
- **评估**能帮助判断一次修改是否真的改善了表现。

## 三、全书路线

- **第 1–6 章：构建 Agent。** 从基础概念出发，学习上下文、记忆、工具、Coding Agent，以及语音和 Computer Use 等交互方式。
- **第 7–10 章：提升 Agent 能力。** 学习评估、模型后训练、持续改进和多 Agent 协作。

如果时间有限，可以先重点学习第 1 章的整体框架和第 2 章的上下文工程。

## 四、我的理解与待验证问题

Agent 的表现不只取决于模型本身，也取决于它在每一步获得的信息、可调用的工具，以及系统如何检查和纠正结果。

后续做实验时，我要持续记录三个问题：

1. Agent 在作出决定时看到了什么？
2. 它调用了什么工具，工具结果怎样影响下一步？
3. 最终结果如何验证，失败后怎样改进？

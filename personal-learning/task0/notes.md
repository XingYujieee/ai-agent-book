# Task 0｜引言笔记

读引言时，我先记下一个式子：`Agent = LLM + 上下文 + 工具`。它不算严格定义，但能帮我把问题拆开。模型决定下一步；上下文是它此刻能看到的东西，包括对话、规则和工具返回；工具让它去查、去算，或者改变外部环境。

我以前用 AI，注意力多在最后的回答。现在想往前多看一步：它为什么会这样答？如果模型没拿到关键资料，或者工具算出了结果却没把结果送回去，最后一句话再流畅也可能站不住。

这本书从构建 Agent 讲到评估与改进。我给自己留了三个问题，后面每章都用得上：

1. 它做决定时，看到了什么？
2. 它实际调用了什么，拿回了什么？
3. 我凭什么相信最后的结果？

我想先学会读过程，再谈如何把系统做得更复杂。
